This repository organizes **10 distinct labs** based on the uploaded **Working with Data** course document. Each lab has a separate directory and its own README, objective, task outline and spaces for original implementations and verified evidence.

**Important:** These are documentation and project scaffolds, **not confirmed completed or tested implementations**. Lab status should be updated only as real code, outputs and evidence are added.

## Workflow

1. Open the lab README for learning objectives and source lab tasks.
2. Add an original, runnable implementation to the lab's `src/` directory.
3. Document Python version, libraries, commands, and required sample datasets.
4. Verify results locally and attach genuine, sanitized evidence.
5. Update each lab's status only after validating execution.

## Responsible Documentation

The uploaded course documents are used to identify topics and activities, not republished verbatim. Avoid sharing third-party course material, private datasets, keys, passwords, or claims of results you have not verified.
